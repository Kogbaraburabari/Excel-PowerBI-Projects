# Excel & Power BI Projects

A collection of data analytics projects built with **Microsoft Excel** and **Power BI**, covering data cleaning, exploratory analysis, data modeling, DAX, and dashboard development.

Each project is organized in its own folder with relevant datasets, analysis files, dashboards, documentation, and key findings where applicable.

## 📊 Projects

| # | Project | Focus |
|---|---|---|
| 1 | [Data Cleaning & Preparation](./DecodeLabs-Internship-Project-1-Data-Cleaning) | Cleaning and preparing a 1,200-row raw sales dataset, including null values, formatting issues, and inconsistent data |
| 2 | [Exploratory Data Analysis](./DecodeLabs-Internship-Project-2-EDA) | Analyzing 1,200 cleaned sales transactions to identify trends, outliers, relationships, and revenue drivers |
| 3 | [Data Visualization & Dashboard Design](./DecodeLabs-Internship-Project-4-Dashboard-Design) | Using pivot tables, KPIs, and dashboard design principles to communicate sales performance |
| 4 | [Logistics Operations Power BI Capstone](./Logistics-Operations-PowerBI-Capstone) | Building a 14-table data model with Power Query, DAX, and a 5-page Power BI report analyzing $262M in logistics revenue |
| 5 | [The Uneven Pandemic: COVID-19 Power BI Dashboard](./AnalystLab-Africa-COVID-Dashboard) | Population-adjusted analysis of global COVID-19 spread using multiple data sources, a star-schema data model, and custom DAX |
| 6 | [Closing the Power Gap](./closing%20the%20power%20gap) | Analyzing global electricity access disparities and identifying countries and economies with the widest gaps in access to power |
