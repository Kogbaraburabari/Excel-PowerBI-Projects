# Project 4: Data Visualization & Dashboard Design

**Tool used:** Microsoft Excel (Pivot Tables & Dashboard)

## Objective
Turn the cleaned and analyzed sales dataset (Projects 1-2) into a visual, stakeholder-ready
dashboard — translating raw pivot table output into a clear, at-a-glance view of business performance.

## Approach
- Built pivot tables to summarize revenue by category (e.g. revenue by product)
- Designed a dedicated Dashboard sheet consolidating key metrics and visuals into a single view
- Focused on clarity over decoration: charts chosen to highlight the story in the data rather than add visual noise

## Key Output
- **Revenue by Product** pivot table, ranking products from lowest to highest revenue contribution
- A consolidated Dashboard sheet summarizing performance at a glance for non-technical stakeholders

## Result
A self-contained Excel workbook where a viewer can go from raw pivot data to a clear visual
summary of sales performance without needing to interpret formulas or raw tables directly.

## Skills applied
`Data Visualization` `Pivot Tables` `Dashboard Design` `Excel` `Stakeholder Reporting`
